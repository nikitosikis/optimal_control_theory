# Лабораторная работа 1 — вариант 11

Задание: поиск минимума с помощью методов статической оптимизации.

Исходные данные:

```text
J(x,u) = 8x² + 6u² + 4xu + x + 3u − 10
c(x,u) = 3x − u² + 1
```

Выполнены все пункты первой лабораторной: минимум без ограничений, минимум при c=0, минимум при c≤0, метод Ньютона-Рафсона и градиентный поиск с апериодической и колебательной сходимостью. Формулы согласованы с лекцией `презентации/ТОУ_1.pdf`, слайды 7–10. В отличие от линейного примера в лекции, в этом варианте производная ограничения по u равна −2u.

## Файлы

- `Лабораторная_1_Вариант_11.pdf` — полный отчёт с выводом формул, доказательством глобальности, пошаговыми таблицами и графиками.
- `lab1_variant11.m` — воспроизводимый MATLAB-скрипт. Дополнительные пакеты не нужны.
- `report.tex` — исходник отчёта в LaTeX с оформлением по образцу ЛСАУ.
- `build_report.py` — генератор таблиц и сборщик PDF; использует Python без дополнительных библиотек и установленный `pdflatex` (MiKTeX или TeX Live).
- `results/` — графики PNG, полные таблицы CSV, результаты JSON и MAT. Файлы обновляются при запуске скрипта.

## Запуск

Откройте `lab1_variant11.m` в MATLAB и нажмите **Run**. Скрипт сам определяет свою папку и сохраняет результаты в расположенную рядом папку `results`.

Начальная точка: (x₀,u₀)=(0,0). Остановка: евклидова норма градиента ≤10⁻⁶. Для градиентного поиска выбраны постоянные шаги 0.05 и 0.09 согласно формуле лекции. Число итераций не включает начальную точку k=0.

Ньютон: 1 итерация. Градиентный поиск: 23 итерации при γ=0.05 и 36 при γ=0.09.

В скрипте проверяются стационарность, допустимость, условия Куна-Таккера, положительная определённость гессианов и сходимость. Для независимой проверки ограниченного решения используется `fminbnd` после сведения к одной переменной. Готовый PDF содержит значения, полученные исполнением MATLAB-скрипта; повторный запуск обновляет численные файлы и графики.

Чтобы заново сформировать PDF после запуска MATLAB, выполните `python build_report.py` из этой папки. Генератор читает файлы из `results`.
