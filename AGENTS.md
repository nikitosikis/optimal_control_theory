# Оформление лабораторных работ

Для отчётов по лабораторным в этой папке используй оформление из `references/ЛСАУ_lab4.pdf`. Пользователь выбрал этот отчёт как образец. Не проси повторно загружать образец, пока он доступен по этому пути.

Параметры оформления записаны в `ОФОРМЛЕНИЕ_ЛАБ.md`. Готовый пример применения — `Лаба1_вариант11/report.tex`. Сохраняй оформление при создании следующих лабораторных: отдельный титульный лист, содержание, чёрные нумерованные разделы и подразделы, набор LaTeX Computer Modern с кириллицей, формулы отдельными строками, подписи рисунков снизу и номера страниц по центру внизу.

Не переноси из образца старые номер лабораторной, вариант, предмет и дату. Для ТОУ пользователь указал вариант 11. Все вычисления должны соответствовать текущему заданию, независимо от образца оформления.
