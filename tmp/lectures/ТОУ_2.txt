Решение задачи (листинг в MATLAB) 
1 2 1 2 0(0) 0, (0) 0, (25) 100, (25) 0, 10x x x x b    
b0=10; 
syms f1(t) f2(t) x1(t) x2(t) 
ode1 = diff(f1) == 0; 
ode2 = diff(f2) == -f1; 
ode3 = diff(x1) == x2; 
ode4 = diff(x2) == b0^2/2*f2; 
  
odes = [ode1; ode2;ode3; ode4]; 
cond1 = x1(0) == 0; 
cond2 = x2(0) == 0; 
cond3 = x1(25) == 100; 
cond4 = x2(25) == 0; 
conds = [cond1; cond2;cond3; cond4]; 
[f1Sol(t),f2Sol(t),x1Sol(t),x2Sol(t)] = dsolve(odes,conds); 
u=f2Sol(t)*b0/2
